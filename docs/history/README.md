# Historical evidence

This directory preserves repository archaeology that is useful for provenance
but is not current implementation guidance. The files are deliberately kept
with their original dates, authorship, and claims; use the current-documents
map in [../README.md](../README.md) before relying on one.

## Coordination packets

[`coordination/`](coordination/) contains the former root-level Fable/Pi/theme
packets and the Fable/Codex exchange log. They document earlier terminal,
plugin/profile, harness, and theme discussions, including proposals that were
superseded by the note-native, direct-PTY, configured-Command product. Their
presence is historical evidence, not an instruction to restore those systems.

- `communications.md` — append-only Fable/Codex coordination log.
- `fable-exo-*.md` — dated architecture, preflight, and wave review packets.
- `custom-pi-implementation.md` — prior Pi-compatible harness proposal.
- `exo-themes-plan.md` — prior theme-system proposal.

The dated packets in [`../reviews/`](../reviews/) remain in place for the same
reason. They may cite old paths or branch names; current source and tests are
the authority for shipped behavior.
