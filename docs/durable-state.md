# Durable-state catalog

Last verified against source at `5a780ab` on 2026-07-24. Markdown and
frontmatter in authorized Note Roots are canonical user knowledge. Everything
under `.exo/` is runtime state or review evidence, not accepted graph
knowledge. This catalog names the remaining persisted artifacts so a maintainer
can trace their authority and recovery behavior before changing one.

| Artifact | Owner and path/scope | Authority | Schema/version | Atomicity and migration | Recovery | Deletion gate | Focused tests |

`WorkspaceFiles` remains the canonical containment authority for Note paths;
this catalog intentionally does not turn any persisted path into an additional
filesystem authorization surface. See [architecture.md](architecture.md).
